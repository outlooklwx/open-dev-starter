# OpenDev Starter

A personal open-source project for web development learning and practice.

## Introduction
OpenDev Starter is an original open-source learning project created for practicing modern web development technologies.  
The project focuses on simple, reusable examples and starter templates, and is intended for personal learning, demos, and knowledge sharing.

## Tech Stack
- HTML / CSS / JavaScript
- (Optional) Vue / React
- (Optional) Node.js

## Usage
This project is mainly used for learning and demonstration purposes.  
Feel free to fork and explore.
